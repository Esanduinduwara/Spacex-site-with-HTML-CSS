# SpaceX Exploration Website

A modern, space-themed website inspired by SpaceX, developed as a frontend web development project using HTML5 and CSS3.

The project focuses on creating a clean, responsive user interface while practicing page structure, styling, forms, navigation, typography, and reusable CSS components.

## Overview

This project presents a fictional SpaceX-inspired website with multiple interconnected pages. It includes a landing page, application form, FAQ section, and terms and conditions page.

The design uses a dark space-themed visual style with high-contrast typography and aerospace-inspired elements.
